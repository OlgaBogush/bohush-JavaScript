### The algorithm

- [x] If the entered number is greater than 7, then print “Hello”
- [x] If the entered name matches “John”, then output “Hello, John”, if not, then output "There is no such name"
- [x] There is a numeric array at the input, it is necessary to output array elements that are multiples of 3

### Answer the questions

**Given bracket sequence: [((())()(())]]**  
**Can this sequence be considered correct?**  
No. Every opening bracket must have a corresponding closing bracket.  
**If the answer to the previous question is “no”, then what needs to be changed in it to make it correct?**  
To ensure the brackets close in the correct order (maintaining the nesting principle), the first parenthesis needs to be replaced with a square bracket.
